## 更新内容

- 今日习惯仅显示每日与提前三天/逾期循环事项。
- AI 卡片显示项目名称；聊天到底后继续滑动整页。
- 周计划定位当天并支持缩放整周；短按约250ms上划完成，动画归位，再点撤销。
- 未完成事项进入次日待安排池，可顺延、取消、放回本周并保留进度备注；日程日期与DDL独立。
- 本地主动复盘通知、免打扰、暂停与稍后一天；28项核心回归及通知虚拟手机专项。
